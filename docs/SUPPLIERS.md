# Поставщики каталога

Документация Aethel: https://mail-api.hvmforum.space/api/docs

При заданных AETHEL_API_KEY и AETHEL_USD_RUB_RATE > 0:

- Gemini AI PRO 18 месяцев, ссылка (Aethel item_id=2): Aethel.
- Варианты ChatGPT Plus: Aethel. Полные условия каждого варианта показаны в карточке.
- Claude, Steam, игры и остальные товары: прежний TheGodShop, прежняя наценка.
- ChatGPT K12 не добавляется: это отдельный продукт, не замена Plus.

Положительные ID товаров принадлежат TheGodShop, отрицательные — Aethel.
В orders сохраняются supplier и supplier_order_ref; в payload — исходная цена
USD, курс, ID поставщика и название. Старые заказы мигрируются как TheGodShop.
Старые карточки и промокод GEMINI100 сохраняют исходный товар TheGodShop #38;
купоны не переносятся на другой товар автоматически.

## Валюта и наличие

API Aethel возвращает USD. Курс задаётся явно с учётом способа пополнения;
по примерам владельца 79 ₽/$0.91, 236 ₽/$2.73, 787 ₽/$9.1 выбран 87 ₽/$.
Закупочная цена округляется вверх до копейки. Обычная наценка 15% сохраняется:
$0.50 → 43.50 ₽ закупка → 51 ₽ продажа. Это не живой валютный курс.

Отсутствующие товары остаются видны с нулевым остатком. При покупке каталог,
цена, остаток и баланс Aethel проверяются повторно. Нет автоматической закупки
у другого поставщика при отсутствии товара или недоступности API.

## Оплата

Опубликованный API Aethel покупает с USD-баланса владельца, общего с их ботом.
Создание покупательских счетов, пополнение и проверка таких счетов не описаны.
Поэтому Aethel работает только через обычную покупку с баланса Atlas Shop,
при достаточном балансе Aethel. Никаких автоматических пополнений нет.
Прямые счета TheGodShop продолжают работать только для своих товаров.

POST /v1/purchases отправляется один раз, с постоянным Idempotency-Key,
вычисленным из сохранённого request_key. Неизвестный результат сохраняет
заказ и средства для ручной проверки; повторного списания не инициируем.
Неожиданный формат успешного ответа сохраняется в payload.supplier_receipt.
GET /v1/purchases/{purchase_id} позволяет получить результат повторно.

## Проверка

Каталог и нулевой баланс проверены реальными GET-запросами при подключении.
Gemini и ChatGPT Plus на момент проверки отсутствовали.
Покупки и ошибки проверяются HTTP-моками. Реальный успешный POST и формат
его ответа ещё не подтверждены: оплаченный контрольный заказ не выполнялся.
Парсер принимает purchase_id и delivery (строка или список строк); другой
формат переводит заказ в UNCERTAIN с сохранением ответа для поддержки.
Ключ хранится в приватном .env, в репозиторий не добавляется.
Локальная проверка: 69 тестов, compileall и git diff --check.
Админ может создать отдельный промокод для Aethel с его отрицательным ID
(/promo_create CODE -2 LIMIT для Gemini). Он не включает прямую оплату.

При выкладке обнаружен периодический сетевой таймаут первого Telegram getMe.
Добавлены ограничение ожидания 15 секунд и повтор подключения без падения
процесса. Полученная идентичность кешируется штатным Bot.me(); неверный токен
и отмена завершения не проглатываются.
